# RUP Flow

Generate RUP documentation, PlantUML diagrams and code in both directions: requirements to models to code, and code back to models.

Version 0.3.2. This branch holds only the plugin: the skill, its two agents and the manifests. It is generated from the main branch on every release; do not edit it.

```
claude plugin marketplace add hector-ae21/rup-flow
claude plugin install rup-flow@rup-flow
```

Documentation, source and issues: https://github.com/hector-ae21/rup-flow
