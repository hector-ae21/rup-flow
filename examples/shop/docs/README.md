# Online shop — RUP documentation

Generated and maintained with the `rup-flow` skill. Every diagram is a `.puml` source with its rendered `.svg` next to it.

| Discipline | Folder | Purpose |
| --- | --- | --- |
| Domain model | [00-domain-model](./00-domain-model/README.md) | Business concepts, ordered by importance to the project |
| Requirements | [01-requirements](./01-requirements/README.md) | Actors, requirements and use-case specifications |
| Analysis | [02-analysis](./02-analysis/README.md) | Analysis classes and use-case collaborations |
| Design | [03-design](./03-design/README.md) | Design classes, sequences, data model and deployment |
| Implementation | [04-implementation](./04-implementation/README.md) | Code map and generation notes |
| Quality | [05-quality](./05-quality/README.md) | Profile, traceability, audits, decisions and open questions |

Paths in this tree can be changed in `rup.config.json`; the folder names above are the defaults.
